# 🌱 Crop Yield Prediction System

A Machine Learning and Data Mining based project that predicts the most suitable crop for cultivation using soil nutrients and environmental conditions.

## 📌 Project Overview

Agriculture plays a vital role in India’s economy. Farmers often face difficulties selecting the right crop due to changing climate conditions and soil quality variations.

This project uses Machine Learning algorithms to analyze:
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH Value
- Rainfall

and predicts the most suitable crop for better agricultural productivity.
